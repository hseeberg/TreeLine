How do I get a GEDCOM file?

Your genealogy service can save your tree as a GEDCOM file. Open the help page for the service you use. It opens in a new tab, so TreeLine stays open here.

  • GeniExport starts from you or from a profile you added.
  • MyHeritageFamily tree → Manage trees → Export to GEDCOM.
  • AncestryTree settings → Export tree. The file arrives as .zip — double-click it to unzip, then choose the .ged file.
  • FamilySearchExports up to 8 generations of your tree.
  • FindmypastFamily tree → View all trees → Export → Download tree.

Desktop programs (Family Tree Maker, RootsMagic, MacFamilyTree, Gramps): look for File → Export → GEDCOM.

Your file stays on this computer. Nothing is uploaded and saved online. No cookies and no tracking.
