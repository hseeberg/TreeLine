### Treeline


TreeLine shows your family tree as a timeline.
Every person is a lifespan bar on one shared time axis.

You see:
- who lived at the same time
- how generations overlapped
- where data is missing (a research to-do list)

[Open TreeLine](https://hseeberg.github.io/TreeLine/) · [Download HTML](https://github.com/hseeberg/TreeLine/blob/main/index.html)

## Start
1. Open TreeLine.
2. Load your own GEDCOM file or try with a sample family.
   GEDCOM (.ged) is the standard export format of Geni, MyHeritage, Ancestry and similar tools.
3. Select a person. You see ancestors, siblings,partners and descendants.

## Why I built TreeLine? 
Most genealogy tools show who is related to whom. They do not show when people lived. A classic tree chart hides that a grandfather and a great-grandchild shared decades, or that siblings were born across 50 years. TreeLine puts time first.

## Privacy
- Your GEDCOM file stays in your browser.
- No cookies. No analytics. No server processing.
- Photos linked in the file are never loaded.
- GitHub Pages may log visitor IP addresses.
  To avoid this, download the HTML file and open it locally.
